# Homebrew tap for Crate

[Crate](https://github.com/jrvgr/crate) is a Mac app for the classic iPod.

```sh
brew tap jrvgr/crate
brew install --cask crate
```

The cask is updated by Crate's release workflow. Crate isn't notarised: macOS asks once, the first time you open it
(System Settings › Privacy & Security › Open Anyway). After that, Crate updates itself.
